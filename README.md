## 👋 About

**CUrBrain** is the official practice repository of our college **Coding Club**.
Every week we solve a fresh set of problems to sharpen our logic, strengthen our
fundamentals in **Java, OOP and DSA**, and build the habit of writing clean code.

This repo holds my solutions, written, tested and improved week by week.

## 🚀 How to Run

```bash
# 1. Clone the repository
git clone https://github.com/rupayanxi5567/CUrBrain_RupayanDey.git
cd CUrBrain_RupayanDey

# 2. Compile a solution
javac q1.java

# 3. Run it
java q1
```

> 💡 If a file starts with `package week_1;`, remove that line before compiling
> from the root folder, or run it inside an IDE like IntelliJ IDEA.
